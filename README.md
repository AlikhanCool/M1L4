# Pokemon Telegram Bot

Telegram-бот на Python, в котором пользователи могут создавать своего покемона, получать его характеристики и взаимодействовать с ним в чате.

## Возможности

* **Создание покемона** по команде `/go` со случайным выбором класса (`Pokemon`, `Fighter`, `Wizard`).
* **Отображение информации и изображения** созданного покемона в чате.
* **Защита от повторного создания** — один пользователь может создать только одного покемона.
* **Игровая логика и сражения** (реализованы в модуле `logic.py`, включая механику атак)[cite: 1].
